# API reference

_Generated by `scripts/gen_api_reference.py`; do not edit by hand._

## MCP tools

Every tool returns JSON. Errors are returned as MCP tool errors whose text contains `{"error": "<code>", "message": "..."}` (codes: `authentication_failed`, `permission_denied`, `not_found`, `validation_failed`, `emergency_stop_active`, `rate_limited`, `platform_error`, `token_expired`). Write tools return `status: approval_required` and an `approval_id` until the owner approves.

## REST management API

Authenticate with `X-API-Key: <key>` or `Authorization: Bearer <key>`. Endpoints marked *owner* need an owner key; *admin* also needs administrator rights. Interactive docs: `/api/docs`.

| Method | Path | Summary |
|---|---|---|
| GET | `/api/accounts` | List Accounts |
| POST | `/api/accounts/kindle` | Create Kindle Workflow |
| POST | `/api/accounts/whatsapp` | Connect Whatsapp |
| PATCH | `/api/accounts/{account_id}/autonomy` | Set Autonomy |
| POST | `/api/accounts/{account_id}/disconnect` | Disconnect |
| POST | `/api/accounts/{account_id}/revoke` | Revoke |
| GET | `/api/analytics/summary` | Analytics |
| GET | `/api/approvals` | List Approvals |
| GET | `/api/approvals/{approval_id}` | Get Approval |
| POST | `/api/approvals/{approval_id}/approve` | Approve |
| POST | `/api/approvals/{approval_id}/cancel` | Cancel |
| POST | `/api/approvals/{approval_id}/execute` | Execute |
| POST | `/api/approvals/{approval_id}/reject` | Reject |
