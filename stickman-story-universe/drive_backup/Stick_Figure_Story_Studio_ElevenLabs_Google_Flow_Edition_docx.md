# 1\. How to use this edition

1\. Voice first. Paste the part's ElevenLabs block into ElevenLabs with the series' voice and settings. Download the MP3. It should land between about 45 and 58 seconds.

2\. Make a character reference. In Google Flow, generate one image per character using the reference prompt in each series. Reuse it as an ‘ingredient’ or reference in every scene so the stickmen stay consistent.

3\. Generate each scene. Paste each scene's Flow prompt, set the aspect ratio to 9:16 portrait and attach the character references. Flow clips are often longer than you need; trim each one to the scene's 3–5 s window.

4\. Edit. Lay the clips over the voice using the time codes and add bold captions, sound effects and quiet music. Add titles and names as on-screen text in the editor, not in the prompt.

5\. Export and post. Export at 1080 × 1920 and switch on the AI-generated label.

## Required style keywords (already in every prompt)

Minimalist black line-art stickman, clean white background, 2D vector animation style, isolated character, smooth motion.

## ElevenLabs settings explained

Stability: lower means more expressive and varied; higher means steadier. 40–50 % suits storytelling.

Clarity + Similarity Enhancement: about 75–80 % keeps speech crisp without artefacts.

Style Exaggeration: 15–30 % adds character; above about 40 % can sound forced.

Speaker Boost: on. Model: Multilingual v2 or the newest high-quality model offered.

Voice names: these are ElevenLabs default or library voices. The line-up changes from time to time, so if a name is missing, search the Voice Library for the alternative or a similar voice.

## Timing rule used

Scene lengths are worked out from the words spoken in each scene at about 180 words per minute (set ElevenLabs Speed to 1.1) (3.0 words per second), clamped to 3–5 seconds. Lines that would run longer than 5 s are split into two scenes, the second at a closer angle. Every part ends with a 3-second call-to-action scene.
